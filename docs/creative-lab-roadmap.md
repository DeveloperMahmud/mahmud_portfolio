# Creative Lab roadmap

## Current release boundary

- Twelve canonical tool records, catalog/detail/demo routes, CMS draft/publish workflow, analytics and Page Studio widgets.
- Six browser-local flagship engines and six mini-tool experiences with honest limitations.
- Secure review workspaces for public-safe assets, comments and exact-version decisions.

## Deliberately deferred

- AI/automation engines, paid APIs and background jobs.
- Confidential review files without private object storage and signed delivery.
- Public Portfolio Presentation Mode until at least two real complete public case studies exist.
- Production claims, client names, outcomes and testimonials without user-supplied evidence.

Future tools should preserve canonical IDs, bounded inputs, explicit privacy copy, deterministic exports, CMS-controlled live URLs and the existing Page Studio integration contract.
